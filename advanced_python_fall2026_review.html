Review for Advanced Python Fall 2026

Read each program and say what it will print. Then check.

  • 2 parts
  • 10 minutes each
  • 14 questions
  • No new syntax

How this works

  1. Read the program. Go one line at a time, top to bottom.
  2. Say what it will print to the person next to you.
  3. Press the button to see what Python really printed, and why.

Part 1 · 10 minutes

Question 1 · Dictionaries

A dictionary holds pairs: a key and the value stored under it. What two lines does this program print?

prices = {"pen": 2, "cup": 5}
prices["cup"] = 6
prices["hat"] = 9
print(prices["cup"])
print(len(prices))

What actually happens

6
3

Line 2 uses the key "cup", which is already in the dictionary, so the value stored under it changes from 5 to 6. Line 4 prints 6.

Line 3 uses the key "hat", which is not in the dictionary yet, so Python adds a new pair. len counts the pairs. There were 2 and line 3 added one more, so line 5 prints 3.

prices[key] = value changes the value when the key is already there, and adds a new pair when it is not.

Question 2 · Dictionaries

Does this program stop with an error? If it does, say the error's name.

prices = {"pen": 2, "cup": 5}
print(prices["Cup"])

What actually happens

Traceback (most recent call last):
  File "Ada_quiz.py", line 2, in <module>
    print(prices["Cup"])
          ~~~~~~^^^^^^^
KeyError: 'Cup'

The dictionary has the key "cup" with a small c. Line 2 asks for "Cup" with a capital C. Python treats capital and small letters as different, so there is no such key and the program stops with a KeyError.

The last line of the error message shows the key Python could not find: KeyError: 'Cup'

A key has to match exactly, capital letters included. Variable names work the same way: score and Score are two different names.

Question 3 · Dictionaries

in asks a yes or no question about a dictionary. What two lines does this program print?

prices = {"pen": 2, "cup": 5}
print(2 in prices)
print("pen" in prices)

What actually happens

False
True

With a dictionary, in looks at the keys only. The keys are "pen" and "cup". The number 2 is a value, not a key, so line 2 prints False.

"pen" is a key, so line 3 prints True.

in checks the keys of a dictionary, not the values.

Question 4 · Remainders

% gives the remainder: what is left over after dividing. What three lines does this program print?

print(14 % 4)
print(12 % 4)
print(3 % 7)

What actually happens

2
0
3

Three 4s fit into 14 and make 12, with 2 left over, so line 1 prints 2.

Three 4s fit into 12 with nothing left over, so line 2 prints 0.

No 7 fits into 3, so all of the 3 is left over and line 3 prints 3.

When the first number is smaller than the second, the remainder is the first number.

Question 5 · Remainders and lists

The list has two names, at index 0 and index 1. The loop makes five passes. What does the program print?

team = ["Ada", "Mo"]
for turn in range(5):
    print(team[turn % 2])

What actually happens

Ada
Mo
Ada
Mo
Ada

turn counts 0, 1, 2, 3, 4. turn % 2 changes those numbers into 0, 1, 0, 1, 0. The index number never goes past 1, so the two names take turns.

Without % 2, the third pass asks for team[2]:

team = ["Ada", "Mo"]
for turn in range(5):
    print(team[turn])

What actually happens

Ada
Mo
Traceback (most recent call last):
  File "Ada_quiz.py", line 3, in <module>
    print(team[turn])
          ~~~~^^^^^^
IndexError: list index out of range

The error's name is IndexError. A list with 2 items has index 0 and index 1, and no index 2.

The last index number of a list is one less than its length.

Question 6 · Strings

Each letter of a string has an index number, starting at 0. What two lines does this program print?

word = "planet"
print(word[0])
print(word[2:5])

What actually happens

p
ane

Index 0 is the first letter, so line 2 prints p.

word[2:5] is a slice. It starts at index 2 and stops before index 5. That is index 2, 3 and 4: the letters a, n and e. Line 3 prints ane. The letter at index 5, t, is left out.

A slice includes its first index number and stops before its second. range(2, 5) counts the same way: 2, 3, 4.

Question 7 · Strings

Line 2 replaces a letter. What does line 3 print?

word = "cool"
word.replace("c", "p")
print(word)

What actually happens

cool

replace makes a new string, "pool", and leaves word as it was. Line 2 does not store the new string under any name, so it is lost. Line 3 prints cool.

To keep the new string, store it under the name:

word = "cool"
word = word.replace("c", "p")
print(word)

What actually happens

pool

Now line 3 prints pool.

replace and strip make a new string. Store it, or it is lost.

Part 2 · 10 minutes

Question 1 · Dictionaries

tally starts as an empty dictionary. The loop looks at one vote on each pass. What two lines does the program print?

votes = ["cat", "dog", "cat", "cat"]
tally = {}
for v in votes:
    if v in tally:
        tally[v] = tally[v] + 1
    else:
        tally[v] = 1
print(tally["cat"])
print(len(tally))

What actually happens

3
2

On the first pass "cat" is not a key yet, so line 7 adds it with the value 1. On the second pass line 7 adds "dog" the same way. On the third and fourth passes "cat" is already a key, so line 5 adds 1 to its value: 2, then 3. Line 8 prints 3.

The dictionary ends with two keys, "cat" and "dog", so line 9 prints 2. Four votes went in, but each key is stored once and len counts the keys.

Question 2 · Functions

The function prints, but it has no return line. What two lines does the program print?

def add_one(n):
    print(n + 1)

result = add_one(4)
print(result)

What actually happens

5
None

Line 4 calls the function, and line 2 prints 5.

The function has no return line, so the call gives the value None. That is what line 4 stores in result, and line 5 prints None.

With return in place of print, the call gives the value 5 to line 4:

def add_one(n):
    return n + 1

result = add_one(4)
print(result)

What actually happens

5

print shows a value on the screen. return gives a value to the line that called the function, so that line can store it or use it.

Question 3 · Functions

Look at the order of the two values in the call on line 4. What does the program print?

def ticket(name, seat):
    return f"{name} sits in {seat}"

print(ticket(12, "Mo"))

What actually happens

12 sits in Mo

Python matches the values in the call to the parameters by position. The first value, 12, goes to name. The second value, "Mo", goes to seat. The program prints 12 sits in Mo.

Python gives no error message here, because every line is allowed. The mistake shows only in the output.

The first value in a call goes to the first parameter, the second value to the second parameter.

Question 4 · Functions

Does this program stop with an error? If it does, say the error's name.

print(square(3))

def square(n):
    return n * n

What actually happens

Traceback (most recent call last):
  File "Ada_quiz.py", line 1, in <module>
    print(square(3))
          ^^^^^^
NameError: name 'square' is not defined

Python runs a file from the top. Line 1 calls square before Python has reached the def on line 3, so the name square has no value yet. The program stops with a NameError.

Every def goes at the top of the file, before any line that does work.

Question 5 · Input and types

The person types 4 and presses Enter. What does line 2 print?

laps = input("Laps: ")
print(laps + laps)

What actually happens

Laps: 4
44

input gives text, even when the person types digits. laps holds the text "4". With two pieces of text, + joins them end to end, so line 2 prints 44.

To add, change the type to a whole number with int:

laps = input("Laps: ")
laps = int(laps)
print(laps + laps)

What actually happens

Laps: 4
8

Now + adds two numbers, and line 3 prints 8.

input gives text. Change the type with int before doing arithmetic.

Question 6 · Comparisons and if

35 is more than 20 and more than 30. What does the program print?

temp = 35
if temp > 20:
    print("warm")
elif temp > 30:
    print("hot")
else:
    print("cold")

What actually happens

warm

Python checks the conditions from the top and runs the lines under the first one that is True. temp > 20 is True, so line 3 prints warm. Python then skips the elif and the else without checking them.

To print hot for 35, put the temp > 30 check first:

temp = 35
if temp > 30:
    print("hot")
elif temp > 20:
    print("warm")
else:
    print("cold")

What actually happens

hot

Now the first condition that is True is temp > 30, and line 3 prints hot.

In an if, elif, else chain, only the first condition that is True runs its lines.

Question 7 · Loops and totals

Say the value of total after each pass of the loop. Then say what line 6 prints.

count = 1
total = 0
while count <= 4:
    total = total + count
    count = count + 1
print(total)

What actually happens

10

The value of total after each pass. total starts at 0, and line 4 adds count to it on each pass: 1, then 3, then 6, then 10.

What line 6 prints. Line 5 makes count one bigger on each pass. When count reaches 5, count <= 4 is False and the loop stops. Line 6 prints 10.

Without line 5, count would stay at 1, the condition would stay True, and the loop would never stop.
