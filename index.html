Beginner Python Quiz

51 questions in 11 rounds. Each one shows a short program and asks what it will do.

Every program on this page was run with Python 3.11.15 when the page was built, and every right answer comes from what it really printed. Newer versions of Python word a few error messages differently, but the error names are the same.

The questions are in build/questions.py. Source: github.com/silvermanjonathan/beginner-python-quiz
